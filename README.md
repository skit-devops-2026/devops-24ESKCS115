## About

MR14 is a poetry-sharing platform where users can write, discover, and share poems.
The application is being built with a React frontend and a Node.js/Express backend connected to MongoDB.

## Tech stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- Authentication: JWT + HTTP-only cookies

## Running locally

```bash
make install
make run
```
